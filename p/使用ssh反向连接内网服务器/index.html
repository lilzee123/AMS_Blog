使用ssh反向连接内网服务器

2026-01-21
阅读时长: 2 分钟

实现 SSH 反向隧道（Reverse SSH Tunnel）可以让你从公网直接访问处于内网（如家里、公司实验室）的服务器。

准备工作

  • 公网服务器（阿里云）：拥有公网 IP，假设为 1.2.3.4。
  • 内网服务器：无法被公网直接访问的 Linux 机器。
  • 本地控制端：安装了 VS Code 的电脑。

配置密钥登录（内网服务器 -> 阿里云）

为了让反向隧道保持稳定且无需手动输入密码，建议配置密钥。

  1. 在内网服务器生成密钥：
1

ssh-keygen -t rsa
  1. 将公钥拷贝到阿里云：
1

ssh-copy-id -i ~/.ssh/id_rsa.pub root@1.2.3.4

建立反向隧道（内网服务器执行） 

1

ssh -fCNR 6000:localhost:22 root@1.2.3.4 -o ServerAliveInterval=60

  • f: 后台运行（容易因意外被杀死）。

  • C: 压缩数据。

  • N: 不执行远程命令（仅转发端口）。

  • R: 反向隧道。

  • 6000:localhost:22: 将阿里云的 6000 端口流量转发到内网机器的 22 端口。

  • o ServerAliveInterval=60: 每 60 秒发送一次心跳包，防止连接断开。

进阶：使用 Autossh 保证连接高可用

反向隧道容易因为网络波动断开。建议在内网服务器安装 autossh 来自动重连。

  1. 安装 autossh：sudo apt install autossh

  2. 运行命令：

1

autossh -M 7000 -fCNR 6000:localhost:22 root@1.2.3.4 -o "ServerAliveInterval 60" -o "ServerAliveCountMax 3"
  • M 7000: autossh 使用 7000 端口监控连接状态。
  1. 使用 nohup 实现后台持久化
1

nohup ./autossh命令 > tunnel.log 2>&1 &

配置 VS Code 访问

使用 VS Code 通过跳板机（Jump Server / Bastion Host）访问内网服务器，最优雅的方式是利用 SSH 的 ProxyJump 功能。这种方式不需要你手动建立多个 SSH 连接，VS Code 会自动处理复杂的转发逻辑。

逻辑架构

你的访问路径如下： 本地电脑 (Client) -> 阿里云服务器 (Jump Server) -> 内网服务器 (Target)

配置步骤

  1. 准备密钥 本地电脑 -> 内网服务器：将本地公钥放入内网服务器的 ~/.ssh/authorized_keys。 注意：密钥是放在本地电脑的，跳板机只是中转站，不需要在跳板机上存储内网服务器的私钥。
  2. 配置 VS Code SSH Config

# 第一层：阿里云跳板机
Host bastion
    HostName 1.2.3.4          # 阿里云公网IP
    User root                 # 阿里云用户名
    Port 22                   # 阿里云SSH端口
    IdentityFile ~/.ssh/id_rsa # 本地私钥路径

Host internal-via-reverse
    HostName localhost        # 对阿里云来说，内网机就在它自己的 localhost
    Port 6000                 # 反向隧道映射的端口
    User myuser               # 内网服务器用户名
    ProxyJump bastion         # 先跳到阿里云
